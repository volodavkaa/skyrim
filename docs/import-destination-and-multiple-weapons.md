# Імпорт архіву: місце збереження та кілька типів зброї

Виправлення за скриншотом користувача, 24.10.2026.

## Причини

Повідомлення `A project with this name already exists or the destination is invalid` виникало до створення плагіна: попередній перегляд відхиляв зайняту папку. У діалозі не було полів, щоб виправити місце збереження без закриття імпорту. Крім того, діалог описував лише один предмет, хоча архів міг містити кілька моделей.

Окремо виявлено неправильне визначення повноти текстурних залежностей: статичний перегляд пропускає приховану геометрію, і ця ознака помилково блокувала ресурсний імпорт. У DarkSister це стосувалося, зокрема, прихованих шарів крові.

## Що змінено

- У діалозі нового проєкту є назва плагіна, батьківська папка, вибір іншої папки та кінцевий шлях. Якщо початкове місце зайняте, пропонується вільна назва; є окрема кнопка повторної пропозиції. Існуючі каталоги й файли не перезаписуються й не видаляються.
- Зміна назви чи папки анулює попередній план. Помилка завершує стан «Перевірка…» зрозумілим повідомленням і залишає налаштування доступними.
- Додано чергу до 100 предметів: «Додати предмет», «Зробити ще один варіант», «Прибрати зі списку». Для кожного окремо обираються назва, тип, основна NIF та спільна/окрема перша особа.
- Дві NIF можна призначити двом типам зброї, а одну NIF — кільком явно створеним варіантам. Кожний предмет отримує власну ідентичність, усі використовують один плагін. Зайві NIF не породжують предмети автоматично.
- План збирає об’єднання потрібних ресурсів усіх рядків. Спільні шляхи копіюються один раз. Уся черга записується в чернетку однією операцією; помилка її збереження відкочує всі додані рядки та нові ресурси. Повторне підтвердження плану не дублює предмети.
- Плагін створюється після підтвердження імпорту. WEAP записуються звичайним збереженням предметів або фінальним пакуванням. Поля призначення з діалогу передаються в майстер, тому він не повертається до старої зайнятої назви.
- Пошук текстур відокремлено від відображення геометрії: перевіряються всі `BSShaderTextureSet`, підтримувані lighting/effect shaders, включно з прихованими частинами. Невідомі або пошкоджені texture/shader-блоки й надалі дають непідтверджений статус. Відсутні DDS не ігноруються. NIF/DDS не переписуються й не конвертуються.

## Як створити обидва варіанти DarkSister

1. Відкрий ZIP у розумному майстрі. Перевір назву й кінцевий шлях у верхній частині діалогу.
2. Для першого рядка вибери «Одноручний меч» і `DarkSister_HD.nif`; за потреби використай її також для першої особи.
3. Натисни «Додати предмет». Для другого рядка вибери «Дворучний меч» і `DarkSister_HD_2h.nif`, признач першу особу.
4. Натисни «Переглянути план усіх предметів». У підсумку мають бути два предмети й один плагін. Підтверди імпорт.
5. Налаштуй характеристики/рецепти предметів у майстрі та створи ZIP.
