## Формат і вибір реалізації

В обох досліджених Skyrim-піднаборах заголовок 20.2.0.7, little endian, user version 12. Stream 83 обирає окремий LE-шлях, stream 100 — попередній SSE-шлях. Таблиці блоків, рядків, коренів та обхід трансформацій спільні. SSE-файл із заміненим stream на 83 відхиляється.

LE використовує `NiTriShape` → `NiTriShapeData` або `NiTriStrips` → `NiTriStripsData`: окремі масиви позицій, нормалей/тангентів, UV та індексів. SSE має інтерлівований `BSTriShape`. Для LE перевіряються також MaterialData, skin instance, додаткові vertex data, розміри, індекси, числа та повнота блоків. Strip-послідовність перетворюється на трикутники з чергуванням порядку вершин; вироджені трикутники пропускаються, кінцева кількість звіряється.

`NiNode`/`BSFadeNode` передають дочірнім блокам масштаб, обертання й перенесення. Контролери та skinning відхиляються явно; видима непідтримувана геометрія не пропускається мовчки. Непідтримувані shader-блоки позначають залежності текстур як невідомі. Для `BSLightingShaderProperty` читаються всі непорожні шляхи `BSShaderTextureSet`, для `BSEffectShaderProperty` — source/greyscale. Рендерер відтворює diffuse і наближене освітлення.
