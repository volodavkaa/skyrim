# Етап 1, завдання 7: базова структурована діагностика плагінів

Додано `PluginDiagnostic`: код, рівень Error/Warning/Unsupported, шлях, запис, причина та рекомендована дія. `PluginValidationService` читає плагін без запису та перевіряє читабельність, заголовки 1.70/1.71, FormID, повторні FormKey, EditorID без урахування регістру в межах одного типу записів поточного плагіна, наявність і читабельність майстрів, їхні безпосередні залежності та порядок. ESL-діапазони застосовуються до власних записів уже light-плагіна або при запиті ESL; звичайні ESP з високими ID залишаються допустимими.

Новий крок `PluginValidationStep` (350) працює після перевірки шляхів і до копіювання. Стандартний DI-конвеєр автоматично виконує його для всіх вибраних плагінів. Критичні помилки потрапляють у Errors і блокують наступні кроки; інші результати — у Warnings. Усі повідомлення доступні в PluginDiagnostics, журналі контексту та логері. Окремий новий екран діагностики належить наступному завданню.

Цільова версія автоматично читається з ресурсів налаштованого SkyrimSE.exe поруч із Data. API також приймає явну Version для перевірок. Заголовок 1.71 блокується для відомої нативної версії до 1.6.1130. Невідома версія дає попередження. Окремого перемикача цільової версії в UI поки немає; встановлену версію не слід вважати вибором іншої цільової збірки. Наявність BEES не визначається автоматично. Підстава для межі версій: [первинна документація розробника Backported Extended ESL Support](https://github.com/Nukem9/skyrimse-backported-esl-support). Програма не встановлює та не змінює цей мод.

## Перевірки

Команди: `dotnet build SkyrimModPacker.sln -c Release --no-restore --verbosity minimal`, `dotnet test SkyrimModPacker.sln -c Release --no-restore --verbosity minimal --logger "trx;LogFileName=plugin-diagnostics-release-fixed.trx" --results-directory artifacts/audit`, `git diff --check`.

Перший повний набір: 471/475, чотири невдалі перевірки. Оновлено очікуваний порядок DI-кроків і дві перевірки ESL для структурованого коду помилки замість старого тексту. У тесті старого JSON-профілю текстову заглушку ESP замінено на синтетичний читабельний плагін; склад ZIP продовжує перевірятися. Пошкоджені плагіни тепер навмисно блокуються також у старому сценарії пакування.

При розширенні тестів виправлено пропущені using для MasterReference/ModKey та помилково розташований using. Ці спроби компіляції завершилися помилками; вони не зараховуються як успішні перевірки. Фінальний результат записаний у TRX `artifacts/audit/plugin-diagnostics-release-fixed.trx`.

## Межі перевірки

Результат не доводить повної сумісності. Окремі Unsupported-повідомлення явно вказують відсутність перевірки цілей WEAP/COBJ/LVLI та перевірки поведінки в грі. Не перевіряються всі типи записів, транзитивний граф усіх залежностей, версії/контрольні суми майстрів, конфлікти з усім порядком завантаження та зворотна сумісність скриптів. Пошкоджені записи можуть спричинити загальну структуровану помилку читання замість діагностики кожного запису окремо.

Ручний запуск UI, xEdit та Skyrim не виконувався. Автоматичні тести використовують синтетичні дані; встановлена гра не змінювалася. Нові перевірки — лише читання. Наступне завдання №8: підтримувані посилання WEAP/COBJ/LVLI, відсутні/видалені записи та показ діагностики в UI.

Фінальний повний набір: **479/479 успішних, 0 невдалих, 0 пропущених**. Збірка без попереджень і помилок; перевірка форматування пройдена.
