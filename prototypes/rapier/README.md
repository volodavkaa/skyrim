# Пробні комплекти рапіри

- [Без піхов](without-scabbard/report.json): шари крові підігнані до клинка, `Scb` відсутній.
- [З піхвами](with-scabbard/report.json): ті самі шари крові та новий `Scb` за перерізами клинка.
- [З ручним коригуванням](adjusted-example/report.json): масштаб 1.05, поворот Z 3°, зсув X 0.5 та Z 0.1, із піхвами.
- `initial-experiment/` містить попередній експорт до підгонки крові й піхов.

У кожній папці комплекта — NIF для першої/третьої особи, JSON повторного імпорту та звіт із SHA-256. Колізійні коробки підігнані до геометрії, але зовнішній вигляд і фізика в Skyrim SE/AE ще не пройшли ручну перевірку. Вхідний ZIP, BSA гри, ESP/ESL та файли проєктів не змінювалися.
